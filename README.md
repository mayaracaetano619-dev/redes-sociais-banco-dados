# Projeto de Banco de Dados 
**Nome do Projeto**: Sistema de postagens e comentários
**Equipe de Desenvolvimento**: Mayara Caetano
## 1. Visão Geral do Sistema (Escopo) 

O sistema é uma rede social onde os usuários podem criar postagens e comentar nas publicações. Cada postagem pertence a um usuário e pode ter vários comentários feitos por outros usuários.

## 2. Requisitos Funcionais (RF)

**RF01**:O sistema deve permitir o cadastro de usuários, armazenando as seguintes informações:
-   Nome completo
-   E-mail
-   Senha

**RF02**:O sistema deve permitir que o usuário crie uma postagem, preenchendo os seguintes campos
-   Conteúdo da postagem
-   Usuário responsável pela postagem

**RF03**: O sistema deve permitir que o usuário faça um comentário em uma postagem, armazenando as seguintes informações:

-   Conteúdo do comentário
-   Usuário que realizou o comentário
-   Postagem comentada
